Обзор платформы

Показатели, трейдеры, операции и управление площадкой

Серверные аккаунты и токены доступа. Owner создаёт трейдерам индивидуальные логины и пароли. После входа трейдер получает ограниченный по времени токен сессии. Реальные платежи и денежный баланс здесь не подключены.
Временное хранилище для проверки входаНа бесплатном хранилище Render аккаунты и Memo могут исчезнуть при его перезапуске. Пока не создавайте постоянные учётные записи для реальных клиентов. Перед запуском потребуется PostgreSQL с постоянным хранением.

Добавить нового трейдера

Укажи индивидуальные данные для входа на сайт OnlyMatch. После создания трейдер сможет войти с указанным логином и паролем.

Трейдеры и персональные Memo

Memo создаётся автоматически вместе с аккаунтом. Можно назначить своё значение, сбросить пароль или временно отключить вход трейдера. Старые Memo остаются зарезервированными.

Для реальных заявок потребуются платёжный провайдер, проверка подписей webhook, идемпотентность, маршрутизация на реквизиты и история событий. Данные локального кабинета трейдера здесь не выдаются за платежи.

Pay-Out · заявки и выплаты

Контроль выплат
Выплаты провайдера пока не синхронизируются

Подготовлены отдельные рабочие разделы для очереди, назначения исполнителей, проверки реквизитов, двухэтапного подтверждения и сверки статусов. Реальный вывод и журнал подтверждений отсутствуют; ничего не будет отмечено выплаченным без платёжного события.

Лимиты и комиссии

Параметры Owner

Рабочая форма подготовки конфигурации. Значения сохраняются только в браузере владельца и пока не изменяют расчёт заявок, курсы или финансы трейдеров.

Темы оформления админки

Внешний вид

Настрой оформление панели Owner. Применяется сразу и сохраняется для этого браузера. Сайт трейдеров не изменяется.
