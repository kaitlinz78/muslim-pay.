Управление трейдерами

Отдельная админ-панель OnlyMatch Owner

Серверные аккаунты и токены доступа. Owner создаёт трейдерам индивидуальные логины и пароли. После входа трейдер получает ограниченный по времени токен сессии. Реальные платежи и денежный баланс здесь не подключены.
Временное хранилище для проверки входаНа бесплатном хранилище Render аккаунты и Memo могут исчезнуть при его перезапуске. Пока не создавайте постоянные учётные записи для реальных клиентов. Перед запуском потребуется PostgreSQL с постоянным хранением.

Добавить нового трейдера

Укажи индивидуальные данные для входа на сайт OnlyMatch. После создания трейдер сможет войти с указанным логином и паролем.

Трейдеры и персональные Memo

Memo создаётся автоматически вместе с аккаунтом. Можно назначить своё значение, сбросить пароль или временно отключить вход трейдера. Старые Memo остаются зарезервированными.

Финансы трейдеров

Для каждого выданного аккаунта отображается только подтверждённый сервером страховой депозит. Рабочий статус разрешён при сумме от 500 USDT. Локальные деньги и суммы незавершённых заявок в расчёт не входят.

Подтверждение депозитов через платёжного провайдера ещё не подключено. До появления подтверждённой записи баланс составляет 0 USDT, работа остаётся заблокированной. Отображаемые суммы нельзя считать независимым доказательством получения средств.

Авторизация не делает демоверсию платёжной системой. Для пополнений и реальных балансов нужна отдельная защищённая бухгалтерия.
